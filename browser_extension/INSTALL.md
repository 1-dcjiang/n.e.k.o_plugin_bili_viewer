# B站接入桥（bili-bridge）扩展安装说明

让 N.E.K.O 的 bili_viewer 插件直接通过浏览器扩展拿到你的 B站登录态，
**装一次永久生效**：登录/退出 B站自动同步，不再需要关闭浏览器、不受残留进程影响。

## 安装（约 30 秒）

### 方式 A：一键脚本（推荐）

1. 双击 **`一键安装B站接入桥.bat`**
2. 脚本会自动把扩展复制到 `文档\bili-bridge-extension` 并打开 `chrome://extensions`
3. 打开页面右上角「开发者模式」→ 点「加载已解压的扩展程序」→ 选择 `文档\bili-bridge-extension` 目录

### 方式 B：手动

1. 打开 `chrome://extensions`，开启右上角「开发者模式」
2. 点「加载已解压的扩展程序」，选择本目录下的 **`bili-bridge`** 文件夹

## 验证

- 工具栏出现「🅱️ B站接入桥」图标（灰色则点一下允许）
- 对 YUI 说"**打开接入面板**"，面板显示「扩展在线」即成功
- 点击扩展图标可查看最近推送时间

## 安全说明

- 扩展仅把 B站登录态推送到**本机 127.0.0.1:8765**（bili_viewer 面板服务）
- 权限只含 bilibili.com 与 127.0.0.1，Cookie 不经过任何外部网络、不上传、不写日志

## 更新扩展

插件升级后重新双击 `一键安装B站接入桥.bat` 即可覆盖更新（扩展随浏览器自动生效）。
